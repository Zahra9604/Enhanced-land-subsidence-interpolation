# Hybrid-CNN-InSAR-Subsidence-Estimation

## Enhanced Land Subsidence Interpolation through a Hybrid Deep Convolutional Neural Network and InSAR Time Series

This repository contains the implementation of the hybrid deep-learning approach presented in:

> **Enhanced land subsidence interpolation through a hybrid deep convolutional neural network and InSAR time series**
> Zahra Azarm, Hamid Mehrabi, Saeed Nadi
> *Geoscientific Model Development*, 2025
> https://doi.org/10.5194/gmd-18-6903-2025

---

## 📌 Overview

Land subsidence is a major environmental and infrastructure hazard. Persistent Scatterer Interferometric Synthetic Aperture Radar (PSInSAR) provides valuable measurements of surface deformation, but PS points are often spatially sparse and unevenly distributed.

This project develops a **hybrid CNN–InSAR framework** for estimating continuous land-subsidence surfaces from sparse PSInSAR observations and spatial/environmental driving factors.

The approach combines:

* PSInSAR-derived land-subsidence observations
* A deep convolutional neural network
* Nine spatial and environmental driving factors
* Traditional spatial interpolation methods for comparison
* Quantitative evaluation using independent training and testing datasets
* Full-area CNN prediction for continuous subsidence mapping

The objective is to estimate land subsidence in areas where PSInSAR observations are sparse or unavailable while preserving the spatial patterns associated with environmental and geological factors.
The classified prediction map can provide a spatial screening tool for identifying areas that warrant further investigation or monitoring.

For a comprehensive **risk assessment**, the predicted subsidence surface can be combined with additional information such as:

* Infrastructure and building locations
* Roads and transportation networks
* Population distribution
* Agricultural areas
* Critical facilities
* Land use and land cover
* Groundwater exploitation
* Geological and soil conditions
* Economic and environmental exposure

Therefore, the framework can serve as a **spatial component of a broader land-subsidence risk-monitoring system**, rather than replacing detailed hazard, exposure, and vulnerability assessments.

# 🚨 Land Subsidence Risk Monitoring

The continuous subsidence surface generated by the hybrid CNN–InSAR framework can support **land-subsidence risk monitoring and early identification of areas experiencing elevated deformation**.

The approach helps overcome an important limitation of PSInSAR observations: persistent scatterer measurements are spatially sparse and may not provide sufficient coverage for continuous monitoring. By integrating PSInSAR observations with spatial and environmental driving forces, the CNN can estimate subsidence across areas where direct PSInSAR measurements are unavailable or unreliable.

The resulting prediction maps can be used to:

* Identify areas with relatively high rates of predicted subsidence
* Monitor the spatial distribution and evolution of subsidence
* Support identification of potentially vulnerable areas
* Provide continuous spatial information between sparse PSInSAR observations
* Assist infrastructure and environmental monitoring
* Support regional land-management and groundwater-management decisions
* Provide a basis for further land-subsidence hazard and risk assessment

# 🌍 Input Data

The CNN uses spatial patches containing nine driving forces associated with land subsidence.

The input structure is:

```text
30 × 30 × 9
```

where the nine channels represent spatial and environmental variables such as:

* NDVI
* Elevation
* Land use
* Groundwater depth
* SPI
* TWI
* Slope
* Aspect
* Distance from groundwater-exploitation wells

The exact input variables and preprocessing steps are implemented in the preprocessing workflow.

---

# 🧠 CNN Architecture

The model is a deep convolutional neural network designed for spatial regression.

The architecture includes:

* 1 × 1 convolutional layers
* 3 × 3 convolutional layers
* Batch normalization
* ReLU activation functions
* Dropout
* Max pooling
* Fully connected layers

The main dense layers include:

```text
1024 → 512 → 256 → 1
```

The hidden layers use ReLU activation, while the final output layer uses a linear activation for continuous land-subsidence estimation.

The network contains approximately **31 layers**, including convolutional, normalization, pooling, dropout, and fully connected layers.

# 🔬 Code Description

## 1. `preprocess.py`

Performs data preprocessing and prepares the datasets required for CNN training.

Main tasks include:

* Loading raster driving forces
* Preparing PSInSAR observations
* Extracting spatial patches
* Constructing the multidimensional CNN input
* Preparing training and testing datasets

---

## 2. `train_subsidence.py`

Trains the CNN model using the prepared spatial patches.

The training workflow includes:

* Loading the prepared dataset
* Training the CNN
* Monitoring model performance
* Saving the trained model
* Generating predictions for the training and testing datasets

---

## 3. `predict_subsidence.py`

Uses the trained CNN to predict land subsidence over the study area.

The model processes the spatial driving-force rasters and produces a continuous prediction surface.

The resulting prediction covers areas where PSInSAR observations may be sparse or unavailable.

---

## 4. `traditional_interpolations.py`

Calculates three traditional spatial interpolation methods using the **training PSInSAR observations**:

### IDW

Inverse Distance Weighting (IDW).

### Ordinary Kriging

Local Ordinary Kriging using the spatial distribution of the training observations.

### RBF

Radial Basis Function interpolation.

The traditional methods use:

```text
Training coordinates
        +
Training Ground_truth
        ↓
Interpolation model
        ↓
Training/Test coordinates
        ↓
Interpolation predictions
```

Importantly, the **test Ground_truth values are not used to construct the interpolation models**.

This prevents test-data leakage.

The script generates:

```text
train_predictions_interpolation.csv
test_predictions_interpolation.csv
```

---

## 5. `compare_interpolation.py`

Compares the CNN predictions with the traditional interpolation methods.

The following methods are evaluated:

```text
CNN
IDW
Kriging
RBF
```

The following metrics are calculated:

* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* Mean Absolute Error (MAE)
* Coefficient of Determination (R²)

Performance is reported separately for:

```text
Training data
Testing data
```

The results are saved in a single comparison file:

```text
MODEL_INTERPOLATION_PERFORMANCE_COMPARISON.csv
```

The resulting table has the following structure:

| Dataset | Method  |   N | MSE | RMSE | MAE |  R² |
| ------- | ------- | --: | --: | ---: | --: | --: |
| Train   | CNN     | ... | ... |  ... | ... | ... |
| Train   | IDW     | ... | ... |  ... | ... | ... |
| Train   | Kriging | ... | ... |  ... | ... | ... |
| Train   | RBF     | ... | ... |  ... | ... | ... |
| Test    | CNN     | ... | ... |  ... | ... | ... |
| Test    | IDW     | ... | ... |  ... | ... | ... |
| Test    | Kriging | ... | ... |  ... | ... | ... |
| Test    | RBF     | ... | ... |  ... | ... | ... |

This provides a consistent basis for comparing the proposed CNN against conventional interpolation approaches.

---

## 6. `Evaluation.py`

Provides quantitative evaluation of the prediction results.

The evaluation workflow calculates statistical performance measures between:

```text
Ground truth
       vs.
Predicted subsidence
```

The evaluation can be applied to the CNN and traditional interpolation results.

---

## 7. `plot_map_subsidence.py`

Generates the final spatial visualization of the predicted land-subsidence surface.

The script converts the continuous CNN predictions into classified spatial categories for visualization.

The resulting map represents the spatial distribution of predicted subsidence and uplift.

---

## 8. `utils.py`

Contains reusable utility functions used throughout the project.

These functions include common processing, prediction, and evaluation operations used by the other scripts.

# 🗺️ Prediction Map

The CNN produces a continuous prediction surface over the valid prediction area.

Conceptually, the output is:

```text
Original raster
┌──────────────────────────────────┐
│ N N N N N N N N N N N N N N N N │
│ N ┌────────────────────────────┐ N│
│ N │                            │ N│
│ N │                            │ N│
│ N │     CNN prediction        │ N│
│ N │     subsidence map        │ N│
│ N │                            │ N│
│ N └────────────────────────────┘ N│
│ N N N N N N N N N N N N N N N N │
└──────────────────────────────────┘

N = NoData
```

The outer NoData region represents areas excluded from prediction because valid input data are unavailable.

The CNN prediction area is generated from the available spatial/environmental driving forces.

# 📊 Model Evaluation

The proposed CNN is evaluated against conventional spatial interpolation methods.

### Deep-learning model

```text
CNN
```

### Traditional interpolation methods

```text
IDW
Ordinary Kriging
RBF
```

The comparison is performed using independent training and testing observations.

The main evaluation metrics are:

### Mean Squared Error

Measures the average squared prediction error.

### Root Mean Squared Error

Measures prediction error in the same units as the target variable.

### Mean Absolute Error

Measures the average absolute prediction error.

### R²

Measures the proportion of variance explained by the predictions.

For model comparison, **testing performance is the primary criterion**, because the testing observations are not used to train the CNN or construct the traditional interpolation models.

---

# 🔐 Avoiding Test-Data Leakage

A key feature of the evaluation workflow is that the testing Ground_truth values are not used to construct the prediction models.

For traditional interpolation:

```text
Training coordinates
+
Training Ground_truth
        ↓
IDW / Kriging / RBF
        ↓
Test coordinates
        ↓
Test predictions
        ↓
Compare with Test Ground_truth
```

For CNN:

```text
Training data
        ↓
CNN training
        ↓
Test input patches
        ↓
Test predictions
        ↓
Compare with Test Ground_truth
```

The test Ground_truth values are used **only for final performance evaluation**.
